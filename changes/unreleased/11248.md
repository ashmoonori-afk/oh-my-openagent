## 2026-10-25 - Opt-in cross-language rerank for Kibitzer recall candidates

`memory.recall.crosslingual` (default off) lets a wake's recall candidates come from a cross-language pipeline instead of the lexical selection. It is inert until the user configures every external setting - `base_url`, `api_key_env`, `judge_model` and `translate_model` have no built-in defaults - and sets `consent` to the exact statement "I agree that omo sends my latest message and excerpts of matching memory notes to the translation and judge models I configured." (exported as `OMO_MEMORY_RECALL_CROSSLINGUAL_CONSENT`; changing the wording invalidates earlier consent). Until then nothing is sent and one warning per session names what is missing or prints the statement. `judge_model` must be a System 1 decision model at `<base_url>/decisions` that answers each card with a constrained verdict (`answers.cN.noul` in [0, 1]): the rerank's correctness depends on that verdict, which is what the measured study used. Before any user text is sent, a fixed synthetic probe checks the reply shape once per `base_url` and `judge_model`; a chat model or any other non-decision reply disables the rerank for that configuration with one warning. Once configured, the pipeline uses the newest user message plus its translations (`view_languages`, default en/ko), a top-32 union per view from the recall BM25 and a TF-IDF cosine over the same recall terms, pointwise scoring by the configured decision model in packets of at most eight, a mean-merged five, and a symmetric pairwise order of those five. The pipeline lives in memory-core `recall/crosslingual.ts` and does no I/O; the Senpi memory component's `recall-crosslingual.ts` is the HTTP client. Both ship in the lazy recall-store sidecar (`extensions/omo-recall-store.js`) and are imported only when the switch is on, so `omo.js` does not grow. Any HTTP error, malformed or out-of-range answer, wrong model id or the shared `timeout_ms` deadline keeps the lexical candidates and logs one warning per session; redirects are refused and responses are capped at 2 MiB. Child-project seats (#10044) stay lexical. Per-agent overrides merge `crosslingual` per field like `event_caps`. Tests: `packages/memory-core/src/recall/crosslingual.test.ts`, `packages/omo-senpi/src/components/memory/recall-wiring.test.ts`.
